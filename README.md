# ![origin_github_banner](https://user-images.githubusercontent.com/673455/37314301-f8db9a90-2618-11e8-8fee-b44f38febf38.png)

This repository contains a client and server utility that is used for delivering team and investor token distributions on vesting schedules.

Node.js 24.22.1 (the current 24.x LTS) is required. The version is pinned in `.nvmrc`, in each package's `engines` field, and in `token-transfer-server/Dockerfile`.
